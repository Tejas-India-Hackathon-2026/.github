# 🚀 Tejas India Hackathon

Welcome to the official GitHub Organization of **Tejas India Hackathon**.

This organization is used for managing team repositories, code submissions, and development activity throughout the hackathon.

---

## 📌 Important Instructions

### 1. Use Only Your Assigned Repository

Each team must push their project code to the repository assigned to them.

Please do not push your project to another team's repository.

### 2. Commit Your Work Regularly

Make meaningful commits throughout the hackathon.

For example:

```bash
git add .
git commit -m "Add user authentication"
git push
```

Avoid making a single commit containing the entire project at the end.

### 3. Keep Your Repository Updated

Make sure your latest working code is pushed to GitHub before the submission deadline.

### 4. Repository Access

Check your **email and GitHub notifications** for the repository invitation.

If you cannot access your assigned repository, please contact the hackathon organizers in the official group.

Team repositories are monitored through the **Tejas India Hackathon Live Development Dashboard**.

* 👥 Participating teams
* 📦 Team repositories
* 💻 Commit activity
* 🏆 Team rankings
* ⏱️ Latest development activity

The dashboard automatically discovers repositories following the hackathon repository naming convention.

---

## ⏰ Submission

Before the submission deadline, make sure:

* [ ] Your latest code is pushed
* [ ] All team members' contributions are available in the repository
* [ ] The project runs correctly
* [ ] Required documentation is included
* [ ] No sensitive credentials or API keys are committed
* [ ] Your final version is available in your assigned repository

---

## ⚠️ Security

**Never commit sensitive information to GitHub.**

Do not push:

```text
.env
API keys
Passwords
Database credentials
Private tokens
GitHub Personal Access Tokens
```

Use environment variables for secrets.
